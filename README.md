# Earthrise — Remotion

ویدئوی عمودی ۱۰ ثانیه‌ای، 1080×1920، نرخ ۳۰ فریم (۳۰۰ فریم).

## اجرا

Node.js نسخهٔ ۲۲ یا بالاتر را نصب کنید، سپس در پوشهٔ پروژه:

```sh
npm install
npm run typecheck
npm run studio
```

## خروجی MP4

```sh
npm run render
```

فایل در `out/earthrise.mp4` با H.264 و yuv420p ساخته می‌شود.
در اولین اجرا ممکن است Remotion مرورگر مخصوص رندر را دانلود کند.

## زمان‌بندی و تصویر

- ۰ تا ۱٫۶ ثانیه: ظاهرشدن تدریجی از سیاهی.
- در کل ۱۰ ثانیه: زوم نرم ۱ تا ۱٫۸ برابر با مرکز ثابت روی زمین.
- ۷ تا ۸٫۲ ثانیه: ظاهرشدن متن فارسی؛ حرکت ۱۸ پیکسلی تا ثانیهٔ ۸٫۴.
- متن تا پایان باقی می‌ماند. صدا اضافه نشده است.

عکس اصلی در `public/earthrise.jpg` به صورت بایت‌به‌بایت کپی شده است.
برای پرکردن قاب عمودی، کناره‌های عکس فقط در نمایش برش می‌خورند؛ هیچ
بازسازی، تصحیح رنگ، اعوجاج، یا تغییری در فایل اصلی اعمال نشده است.
متن در فضای سیاه بالای زمین است و تصویر زمین را نمی‌پوشاند.

فونت فارسی از فونت‌های سیستم انتخاب می‌شود (در macOS معمولاً Geeza Pro).
برای خروجی کاملاً یکسان روی دستگاه‌های متفاوت، همان فونت فارسی را روی
همهٔ دستگاه‌ها نصب کنید؛ فونت اختصاصی در این بسته بازتوزیع نشده است.

## وضعیت بررسی

یکسان‌بودن بایت‌به‌بایت کپی عکس تأیید شده است. محیط سازنده Node.js/npm نداشت؛
نصب وابستگی‌ها، بررسی TypeScript و پیش‌نمایش مرورگر در آن اجرا نشده‌اند.
